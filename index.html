Setup Resume Matcher (3 steps)

Runs on your computer only. This page stays your job tracker — Docker runs the resume tool locally.

⚠️ Step 0 — Chrome flag (required once)

Open chrome://flags/#unsafely-treat-insecure-origin-as-secure, add http://localhost:18765, Enable, relaunch Chrome. This tells Chrome to allow http://localhost:18765 from this https:// site.

1
Install Docker Desktop

Install, open it, wait until it says Running.

Download Docker Desktop
2
Copy the setup command

No file download — avoids browsers renaming to .txt. Pick your OS, copy, then paste in Terminal.

3
Run it

Open Terminal, paste the copied command, press Enter. First run ~2 min.

mkdir -p ~/resume-matcher && cd ~/resume-matcher && …

Copy the http://localhost:… line from Terminal and paste it in the URL field above.

Prefer a file? Download zip (correct name inside). Browsers often save scripts as .sh.txt — that breaks docker compose up -d; use copy-paste instead.
